# 工作流预设（给 AI 读）

这个目录里的 `*.json` 就是「工作流推荐预设」。用户点「⋯ → 添加工作流预设」时，插件把选中的预设画进当前这张关系图；你也可以直接读这些文件，按同样的骨架帮用户补图。

## 结构

```json
{
  "id": "project-flow",
  "name": "项目工作流",
  "note": "一句话说明",
  "main": [{ "name": "需求", "verb": "" }, { "name": "设计", "verb": "定下" }],
  "side": [{ "name": "参考素材", "from": "设计", "verb": "取数" }]
}
```

- `main`：**主干**，按数组顺序连成一条线（左边的线动词写在下一个节点之前的边上）。
- `side`：**侧枝**，`from` 指向主干（或别的侧枝）里的节点名，挂在它下面。
- 名字就是节点名（不必唯一，同名会共用备注，但各有 id）。

## 画图约定（用户定的）

1. 总项目 = 一条主干线，从左到右。
2. AI 制作或后期添加的东西 = 侧枝，挂在相关主干节点下面，不要串进主干。
3. **尽量少用循环**；确实要回环时，用「同名的另一个节点（新 id）」代替反向连线，避免环。
4. 边上写"动作 + 对象"，不要空着。

## 怎么加一个预设

新建 `presets/<id>.json`，按上面的结构写；同一目录多个预设时，默认用第一个（按文件名排序）。加完不用改代码。
